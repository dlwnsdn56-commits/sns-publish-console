# SNS 발행 콘솔 (내부 v1)

영상 SNS 대행 운영자용 발행 콘솔입니다. 로그인 없음. 클라이언트 2곳(A/B)만 사용합니다.

## 실행 방법

프로젝트 폴더에서 의존성을 설치한 뒤 개발 서버를 켭니다.
브라우저에서 http://localhost:3000 을 엽니다.

- 기본 바인딩: 0.0.0.0:3000
- 포트 변경: 환경변수 PORT

## 화면

1. 새 발행 — 클라이언트 선택, 영상 1개 또는 카드뉴스(이미지 여러 장), 캡션, 선택 예약 시각, 채널 체크 후 등록
2. 작업 목록 — 작업별 채널별 상태
3. 네이버 큐 — 네이버 블로그 / 네이버 클립 중 상태가 수동 대기인 항목만. 캡션과 파일명 확인 후 완료

모든 작업에는 clientId가 붙습니다. 새로고침해도 data/jobs.json 과 uploads/ 에 남습니다.

## 스텁된 것 (실 API 호출 없음)

- Instagram, Facebook, Threads, X, TikTok, YouTube: adapters 폴더 스텁. 짧은 지연 후 상태를 발행됨(시뮬) 로 표시
- 네이버 블로그, 네이버 클립: 자동 업로드 없음. 수동 대기 후 운영자가 직접 올린 뒤 완료

공식 소셜 API 연동, 네이버 업로드 자동화는 구현하지 않았습니다. 예약 시각은 저장만 하며 v1에서는 시간에 맞춰 자동 발행하지 않습니다.

## 다음 단계

1. OAuth — adapters 각 모듈의 publish 함수에 토큰과 업로드를 연결
2. 클라이언트별 계정 — 클라이언트마다 연결된 소셜 계정 저장
3. 네이버 RPA 워커 (별도 프로세스) — 큐의 수동 대기 작업을 받아 허용된 방식으로 처리. 이 콘솔은 큐와 완료 표시만 담당
4. 로그인과 권한 — 운영자 인증, 감사 로그
5. 예약 발행 워커 — scheduledAt이 되면 스텁 또는 실 API를 호출

## 데이터

- 작업: data/jobs.json
- 업로드 파일: uploads/

## 명령
설치 후 개발 서버: 이 폴더에서 패키지 설치 스크립트와 dev 스크립트를 실행합니다. package.json 의 scripts.dev 가 서버를 켭니다.

정확한 명령:
cd /workspace/sns-publish-console
npm install
npm run dev
